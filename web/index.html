    Kontrol layar sentuh (HP / tablet)

    Stik analog mengirim stik kiri DualShock. Tombol A di layar menyalakan mode analog (seperti tombol ANALOG asli) untuk game yang mendukungnya.

    Gestur langsung di layar game

    Tap = tombol di bawah · Tap 2 jari = tombol kedua · Tekan & tahan = menahan tombol tap · Geser & tahan = arah.

    Klik sebuah tombol lalu tekan tombol keyboard / gamepad yang diinginkan. Esc = kosongkan.
