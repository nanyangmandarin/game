PlayStation 1 di browser

Emulator berjalan sepenuhnya di perangkat Anda (WebAssembly). Tidak ada file yang diunggah ke server.

  1. BIOS: belum ada —
  2. Game: klik Buka Game atau seret file ISO / BIN+CUE ke sini.

BIOS (mis. SCPH-1001 / SCPH-5501 / SCPH-7502) harus diambil dari konsol milik Anda sendiri. Ukurannya 512 KB.
